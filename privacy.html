Privacy policy

Last updated: 12 November 2026

What this covers

This policy covers "Worst Decisions analytics", an internal tool run by Night Ledger Studio for its own YouTube channel, Worst Decisions (@TheWorstDecisions). It is not offered to the public.

What data it accesses

With the channel owner's permission, given through Google's sign-in, the tool reads two things through official Google APIs, read-only:

  • YouTube Analytics reports for the channel's own videos (scope: yt-analytics.readonly), such as views, watch time, likes, comments and subscribers gained.
  • Basic details of the channel and its uploaded videos (scope: youtube.readonly), such as titles and publish dates.

It cannot upload, edit or delete anything, and it never sees a password.

How the data is used

The numbers are used only to decide which video topics to make next. They are stored in a private file that only the channel owner can access. They are not sold, shared or used for advertising.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The channel owner can revoke access at any time at myaccount.google.com/permissions. Stored analytics files are then deleted on request.
